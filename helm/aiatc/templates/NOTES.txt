🔍 Useful Commands:
==========================================

View pods:
  kubectl get pods -n {{ .Release.Namespace }}

View services:
  kubectl get svc -n {{ .Release.Namespace }}

View Dapr components:
  kubectl get components -n {{ .Release.Namespace }}

Check scenario service logs:
  kubectl logs -l app.kubernetes.io/component=scenario-service -n {{ .Release.Namespace }} -c scenario-service

Check web service logs:
  kubectl logs -l app.kubernetes.io/component=web -n {{ .Release.Namespace }} -c web

Test scenario service health:
  kubectl port-forward svc/{{ include "aiatc.fullname" . }}-scenario-service {{ .Values.scenarioService.service.grpcPort }}:{{ .Values.scenarioService.service.grpcPort }} -n {{ .Release.Namespace }}
  curl http://localhost:{{ .Values.scenarioService.service.grpcPort }}/health
